# 4 Elos Pescados

Site estático em HTML, CSS e JavaScript, pronto para GitHub Pages.

## Catálogo atual

Somente os 17 produtos embalados enviados pelo cliente em 30/10/2026 são exibidos. Fotos, nomes, pesos e origens correspondem às embalagens fornecidas. As categorias e a seção de embalagens também usam essas fotos. O PDF antigo deixou de ser oferecido na página para não apresentar itens removidos. Arquivos antigos permanecem no histórico/repositório, sem aparecer no catálogo.

As imagens decorativas do mar e do barco são ilustrativas geradas por IA. E-mail e endereço são os dados fornecidos pela empresa. Nenhum novo telefone ou WhatsApp foi acrescentado.

## Publicar

Envie index.html, style.css, script.js, produtos.json, .nojekyll e assets para a raiz da branch main. Em Settings → Pages, selecione Deploy from a branch, main e /(root). Aguarde a conclusão da publicação.

## Manutenção

Atualize index.html e produtos.json juntos ao alterar produtos. O menu e os filtros ficam em script.js; o visual, em style.css.
