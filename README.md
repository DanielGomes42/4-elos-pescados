## Publicar no GitHub Pages

Envie o conteúdo desta pasta para a raiz da branch main. Em Settings → Pages, selecione Deploy from a branch, main e /(root). Aguarde a conclusão da publicação.

## Arquivos

- index.html: conteúdo, catálogo e SEO.
- style.css: layout e adaptações de tela.
- script.js: menu e filtros.
- produtos.json: relação dos 17 produtos; atualizar junto com o HTML.
- assets: fotos e identidade visual.

Abra index.html para visualizar. Os links de WhatsApp abrem uma conversa e não enviam mensagens automaticamente. O mapa usa um iframe do Google Maps e carrega sob demanda.
